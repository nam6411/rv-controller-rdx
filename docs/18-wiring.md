# 18. 배선도 — §12 Radxa 통합 노드

rv-controller [`docs/18-wiring.md`](https://github.com/nam6411/rv-controller/blob/master/docs/18-wiring.md)에서 §12만 옮겨 왔다. 절 번호는 그대로 두어
다른 문서의 "docs/18 §12.x" 참조가 이 파일을 가리킨다. §0(공통 전원)~§11(ESP 노드)은 rv-controller 쪽에 있다.

## 12. Radxa 통합 노드 — BLE 3개 + 433MHz + 버드뷰 시점 + GPS (Radxa ZERO 3W 1GB, 계획)

> **계획 (2026-10-19)** — 아직 만들지 않았다. MACH·JBD·TPMS(BLE)와 버드뷰 CC1101 송신을 Linux 보드 한 장으로 모으고,
> 버드뷰 트리거(후방·좌·우)를 GPIO로 조작한다. GPS(BE-880)·나침반도 여기 단다 (docs/24).
> MaxxFan IR은 §11 노드에 그대로 둔다.
> 소프트웨어 쪽(넘길 기능·옮기는 순서)은 [29-radxa-node.md](29-radxa-node.md).
> BLE는 **내장 AIC8800(Wi-Fi·BT 겸용)으로 먼저 시도한다** (2026-10-21). 연결이 불안하거나 BLE 장치 3개(MACH·JBD·TPMS)를
> 버티지 못하면 그때 USB BT 동글(RTL8761B, 외장 안테나)을 단다 — docs/29 §5 1단계에서 판단.

ZERO 3W 헤더 GPIO는 전부 **3.3V(최대 3.63V), 5V 톨러런트 아님**. 12V 신호는 모두 PC817로 분리한다.
핀맵 출처: [Radxa ZERO 3 Hardware Interface](https://docs.radxa.com/en/zero/zero3/hardware-design/hardware-interface).

### 12.1 핀 배정 (40핀 헤더)

만능기판을 **뒷면 맨선 한 층, 점퍼 없이** 배선하려고 핀을 골랐다(§12.4). 소켓(J5)의 홀수 핀 줄(E행)은 위로,
짝수 핀 줄(F행)은 아래로만 빠져나갈 수 있으므로 위쪽 장치(CC1101·버드뷰 UART)는 홀수 핀, 아래쪽(전원·GPS·입출력)은 짝수 핀이다.

- **CSN을 GPIO(핀 15)로 둔 이유** — SPI3 CS0(핀 24)는 짝수 줄이라 위쪽 CC1101로 가려면 다른 선을 건너야 한다.
  CC1101은 CSn을 내린 뒤 SO가 Low가 될 때까지 기다려야 해서 어차피 CS를 소프트웨어로 쥐는 편이 맞다.
  핀 24는 기판에 잇지 않는다. RK3566 SPI는 `SPI_NO_CS`를 받지 않으므로(2026-10-29 실측, EINVAL) spidev는 보통대로 열고
  CS0는 빈 핀 24에서 혼자 움직이게 둔 채 CSN(핀 15)만 GPIO로 내린다. 칩 확인: PARTNUM 0x00, VERSION 0x14.
- **입력 풀업** — 기판 풀업 저항은 없다. SoC 내부 풀업을 쓰는데, **Rockchip GPIO 드라이버는 `gpiod`의 `bias=pull-up` 요청을 적용하지 않아**
  칩 기본값(풀다운)이 남는다(2026-10-29 실측 — 옵토가 꺼져 있어도 0으로 읽혀 ACC·트리거가 켜졌다). 그래서 핀 22·28·32·37을 부팅 때
  풀업으로 거는 오버레이 `rvnode-inputs-pullup`(radxa 저장소 `dts/`, `deploy.sh`가 설치)을 쓴다. 핀 28은 보드의 I2C 풀업도 있다.
  옵토 출력이 기판 안에서 짧게 끝나므로 내부 풀업으로 충분하다. 깜빡이 신호는 소프트웨어로 디바운스한다.
- **UART3(핀 3·5)** 에는 보드 I2C 풀업이 달려 있다. UART는 쉴 때 High라 문제없다(GPIO로 쓸 때만 이상 동작).
- **쓰지 않는 핀**: 1(3.3V), 6·30·39(GND), 8·10(UART2 = Radxa OS 디버그 콘솔, 1500000bps — 부팅이 안 될 때 이걸로 들어간다),
  24(SPI3 CS0), 26(NC), 27(I2C 풀업). 예비: 7, 11, 12, 13, 33.
- **핀 35는 부팅하는 동안 High로 튀면 안 된다** — 튀면 버드뷰가 부팅마다 잠깐 켜진다. 보드가 오면 부팅 중 핀 35 전압부터 본다.
- `rsetup` → Overlays에서 **SPI3-M1**(→ `/dev/spidev3.0`), **UART3-M0**(버드뷰), **UART4-M1**(GPS), **I2C5-M0**(나침반 → `/dev/i2c-5`)을 켠다.
  나침반은 `i2cdetect -y 5`로 주소를 확인한다(QMC5883L = 0x0D, HMC5883L이면 0x1E).
  장치 이름(`/dev/ttyS3`·`/dev/ttyS4`)은 켠 뒤 `dmesg | grep tty`로 확인한다.

**트리거를 AVM 전원에서 받는 이유** — 버드뷰가 꺼져 있는데 트리거선에 12V를 넣으면 입력 보호 다이오드를 통해
본체가 반쯤 켜질(역급전) 수 있다. 처음에는 버드뷰 ACC선을 J2-1로 끌어와 본체가 꺼지면 트리거도 0V가 되게 했다.
**AVM 켜짐 회로(2026-10-25)를 더하면서 J2-1은 버드뷰 상시(BATT)선으로 바꾼다** — U7이 J2-1로 ACC를 만들기 때문이다.
그래서 이제 ACC가 꺼져 있어도 트리거 출력에 12V가 나갈 수 있다. **rvnode는 핀 35(AVM 켜짐)가 High일 때만 트리거 핀(36·38·40)을
High로 하고, AVM을 끌 때는 트리거부터 내린다** — 소프트웨어 인터록.

**트리거 입력이 active-low로 측정되면** (입력을 비워 둔 채 5V·12V가 보이면) 출력 단을 바꾼다:
PC817 C → 트리거선, E → GND. R4·R13과 J2-1(AVM_12V)은 빼고, GND를 버드뷰 GND와 공통으로 잇는다. 로직은 그대로(High = 켬).

### 12.3 부품 목록

> **2026-10-21 주문 부품 기준.** 지금 배치는 Radxa를 2×20 암 소켓에 바로 꽂는 안이고, 구멍 위치·배선 순서의 기준은
> 그림 페이지(https://claude.ai/artifact/UK2Uu3axFP58i3WWnQmWcJ, 사본 [artifacts/radxa-baseboard.html](artifacts/radxa-baseboard.html) — 브라우저로 연다)다.

### 12.4 만능기판 배치 — 뒷면 직각 맨선 (점퍼는 나중에 더한 AVM 켜짐 회로의 피복선 2가닥)

Radxa는 **2×20 암 소켓(J5, H8.5mm)에 바로 꽂아** 베이스보드 위 2층에 얹는다. 소켓은 다른 부품처럼 윗면에 달고,
Radxa의 수 헤더는 **Radxa 뒷면**(부품 없는 쪽)에 납땜해 부품면이 위를 보게 꽂는다 — 윗면에 달면 거울상이 돼서
5V가 엉뚱한 핀에 들어간다. J5 1번 = `E-E`(E열·E행, 오른쪽 끝 위 줄). Radxa는 A~F행 위를 덮고 판 위쪽 가장자리 밖으로 약 1cm 나간다.
판 윗면에서 Radxa 밑면까지 약 11mm(소켓 8.5 + 헤더 받침 2.5)라 Radxa 밑의 J4·J7·J8은 측면 진입 Molex 5046이다(§12.3).

판은 PY 7×9cm(31열 × 26행)이다. 구멍 이름은 판 실크 글자 그대로 **열 글자-행 글자**(예: `K-L` = 위쪽 K열, 왼쪽 L행)다.
행은 왼쪽 실크대로 위에서부터 A~Z. 열은 위쪽 실크대로 **오른쪽 끝부터** A~Z를 센 뒤 다시 A~E로 돌아가므로
두 번째 바퀴의 왼쪽 5열은 `A′~E′`로 적는다(위쪽 실크 글자는 뒤집혀 찍혀 있다). 맨 오른쪽 A열은 비운다. 아래 Y행은 단자 몸통 밑이고, Z행에는 나중에 더한 R22·R23과 맨선이 들어간다.

배선 요령:
- 한 줄 = 곧은 맨선 한 가닥. 지나가는 구멍마다 패드에 납땜한다. 꺾이는 곳은 같은 네트 두 가닥을 한 구멍에서 겹쳐 납땜한다.
- 옆 구멍은 대부분 다른 네트다. **땜납이 옆 패드로 번지지 않게** 한다. 특히 J5의 E·F행 패드 사이.
- 5V·GND·12V 가닥은 굵은 선(0.8mm 이상). 나머지는 0.5~0.6mm.
- PC817은 점(1번 핀) 방향을 그림대로. 입력(U4~U6)은 LED가 아래(단자 쪽), 출력(U1~U3)은 LED가 위다.
- 단자 순서(왼쪽부터): J1 = GND·+12V, J3 = CAR·REV·R·L·G13 (5P), J2 = AVM·RIGHT·LEFT·REAR·ACC (5P). J6(GPS) = RX·TX·GND·5V, J7 = GND·SCK·MISO·MOSI·VCC·CSN.
- PS1(MP1584)은 단선 다리 4개로 띄워 단다. + 쪽(IN+·OUT+)이 왼쪽(H열)이다. 꽂기 전에 출력을 5.0~5.1V로 맞춘다.
- 입력 GND(J1·PS1 IN−)는 `J-L`–`J-T`·`J-T`–`F-T` 두 가닥으로 판 위 GND에 직접 묶는다 — MP1584 안의 GND에만 기대지 않는다.
  J4·J7 GND는 판 위에서 Radxa GND 핀(9·25)으로만 가고 Radxa 안에서 나머지 GND와 이어진다. 그래서 Radxa를 뺀 채로는
  J4·J7 GND(`D-A`·`Q-B`)와 J1 GND(`F-X`) 사이가 열려 보인다. 검사 스크립트는 Radxa 핀끼리의 내부 연결만 넣고 본다.
- **AVM 켜짐·차 시동 회로는 납땜을 마친 뒤 더한 것이다 (2026-10-25).** 기존 판에서 바꾸는 것은 세 가지뿐이다:
  **J2·J3 헤더를 4P → 5P로 교체**(J2 = 버드뷰 묶음 AVM12V·RIGHT·LEFT·REAR·ACC, J3 = 견인차 묶음 CAR·REV·R·L·G13),
  **후진 맨선을 W행으로 옮김**(`S-V → S-X → Q-X`를 떼고 `S-V → S-W → Q-W → Q-X` — CAR 핀 `S-X`가 들어갈 자리를 비운다), 나머지는 더하기만 한다.
  - AVM 출력: U7 `U-S~T-V`(R13·R9 사이, 양옆 0.4mm), R21 `R-S~R-V`. U7 컬렉터는 S행 AVM12V 끝(`V-S`)에서 V열로,
    GND는 N행 버스(`U-N`)에서 U열로 내려오고, 이미터는 `U-W → V-W → V-X`(J2 ACC). R22는 Z행 `Z-Z~V-Z`, GND는 `D′-N → E′-N → E′-Z`.
  - 차 시동 입력: U8은 J3와 J1 사이에 90° 돌려 `J-U`(A)·`J-V`(K)·`G-V`(E)·`G-U`(C). K는 K열 G13(`K-V`)에, E는 F열 GND(`F-V`)에 붙는다.
    D5 `I-W~I-Z`, R23은 Z행 `S-Z~O-Z`. 차 12V는 J3 CAR `S-X → S-Z`(R23), R23 뒤 `O-Z → H-Z → H-U → J-U`.
  - 핀 35·37은 둘레가 막혀 맨선으로 나올 수 없어 **피복선**: `V-E → R-V`(R21), `W-E → G-U`(U8 C). 핀 37 바로 위 `W-D`가 3.3V다.
  - Z행 윗면의 R22·R23은 J2·J3 플러그 플라스틱 앞이다 — 플러그를 끝까지 꽂아 걸리지 않는지 본다.
- **새로 생긴 12V–GND 이웃 줄**(AVM 켜짐 회로): E′열 GND(N~Z행)가 D′열 AVM12V(S~X행)와, U열 GND(N~S행)가 V열 AVM12V(P~S행)와
  나란히 지난다. 땜납이 번지면 버드뷰 전원이 GND로 쇼트되므로 이 두 곳은 납땜 뒤 멀티미터로 따로 본다. 그 밖에 `V-X`(ACC)↔`W-X`(후방 트리거),
  `S-X`(차 12V)↔`S-W`(후진), `W-E`(핀 37)↔`W-D`(3.3V)도 이웃이다.
- 납땜이 끝나면 Radxa를 꽂기 전에 멀티미터로 J1 +12V↔GND, 5V↔GND, J3 G13↔GND, J2 AVM12V↔GND, J3 CAR↔GND가 **열려 있는지**부터 본다. J2 ACC↔GND는 R22를 달면 약 47kΩ, 지금처럼 빼 두면(2026-10-28) 열려 있어야 한다.

                            │    4번 우 깜빡이 → R

- **단자박스 TB1** (BC-ABB-S10PT 내장 10P 계단형, 5+5): 하네스를 여기서 받아 1~5 = AVM12V·RIGHT·LEFT·REAR·ACC → J2,
  6~10 = CAR·REV·R·L·G13 → J3 (플러그 순서 그대로). 쇼트바는 쓰지 않는다 — 특히 5(ACC)·6(CAR) 사이와 10(G13)은 잇지 않는다. F3는 13핀 10번 → TB1-6 사이.
- **GND 공통**: J1 GND, 버드뷰 GND, Radxa GND는 같은 차체 GND다(J2는 하이사이드라 버드뷰 GND를 따로 끌 필요 없음).
  J3 쪽만 절연 — 견인차 GND와 섞이지 않는다.
- **13핀 분기**는 카라반 쪽 분배함(13핀 케이블이 들어오는 정션 박스)에서 따는 게 깔끔하다. 옵토 LED는 약 5mA라
  견인차의 트레일러 램프 감지(전구 끊김 경고)에 영향이 없다.
- 트리거 출력은 **버드뷰 매뉴얼의 트리거선 색**에 맞춘다. 연결 전에 버드뷰를 켜고 트리거선마다 확인한다:
  ① 선을 비워 둔 채 GND 기준 전압 — 약 0V면 high-active(이 회로 그대로), 5V·12V가 보이면 active-low(§12.2 끝의 변형).
  ② high-active면 1kΩ을 거쳐 3.3V → 5V → 12V 순으로 넣어 시점이 바뀌는 최소 전압을 적어 둔다.
- **ACC_IN 전류를 먼저 잰다** (AVM 켜짐 회로). 카라반 12V → 1kΩ → ACC_IN으로 넣고 1kΩ 양단 전압을 본다(1V = 1mA).
  버드뷰가 켜지고 2mA 안쪽이면 §12.2 A안, 넘으면 B안(하네스 쪽 릴레이). 차 시동 12V는 시동·ACC에 따라 켜지는 선(13핀이면 10번)에서
  받고, 귀환 GND는 J3 G13(13핀 3번)을 같이 쓴다 — 견인차 GND는 옵토 LED 쪽에만 닿는다.
- 시점 매핑(예: 좌 깜빡이 → 우측방, 평상시 → 후방)과 깜빡이 유지 시간(마지막 펄스 뒤 약 1.5초)은 소프트웨어로 한다.
- **GPS 자리**: 하늘이 보이는 창가나 FRP 지붕 바로 아래. 금속 판·강압 모듈·Radxa에서 떨어뜨린다.
  Radxa는 RTC 전지가 없어 GPS 시각을 `gpsd` + `chrony`로 시스템 시계에도 쓴다 (LTE가 끊겨도 시각이 맞는다).
- **USB 3.0 잡음**: Host USB-C(USB 3.0)는 SuperSpeed로 돌 때 2.4GHz와 GPS 대역에 잡음을 낸다고 알려져 있다.
  캡처 모듈은 USB 2.0 장치라 SuperSpeed 선이 쉬어 이 문제가 작다. 그래도 GPS는 Radxa·USB 케이블에서 멀리 둔다.
- **내장 BLE**: AIC8800 안테나는 Radxa 보드의 온보드/IPEX 안테나다. 함체가 금속이면 BLE·Wi-Fi가 약해지므로 플라스틱 함체로 하고,
  IPEX 외장 안테나를 쓸 수 있으면 함체 밖으로 뺀다. Wi-Fi와 BT가 한 칩의 2.4GHz를 나눠 쓰므로 공유기가 되면 Wi-Fi는 5GHz로 붙인다.
  동글로 바꿀 때(§12 머리말) 동글은 짧은 USB 연장선으로 Radxa에서 10cm 이상 띄운다.
